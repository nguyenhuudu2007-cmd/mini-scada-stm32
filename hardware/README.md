# Hardware Artifacts

Thư mục này dùng để lưu bằng chứng phần cứng của dự án:

- `schematic/` *(dự kiến)*: File sơ đồ nguyên lý KiCad (`.kicad_sch`) và bản xuất PDF/PNG.
- `photos/` *(dự kiến)*: Ảnh chụp mạch thực tế và góc Servo trên bàn test.
- `pulseview/` *(dự kiến)*: Ảnh chụp dạng sóng I2C / PWM / UART trên Logic Analyzer.
